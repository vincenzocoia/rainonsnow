=== Data-generating process ===
F(x) = F_GEV(x; mu, sigma, xi) * Phi((x - a)/b)   [ = cdf of max(GEV, Normal) ]
  GEV:    mu = 0, sigma = 1, xi = 0.2
  Normal: a  = 1.5, b     = 0.8
  true support: [-5, Inf)
The normal contaminates the body and vanishes in the tail, so the GEV is
the exactly correct TAIL model and a wrong BODY model.

=== Weight function ===
smoothstep, 0 below p0 = 0.95, 1 above p1 = 0.98
p0 sits where contamination ~ 1e-2 (quantiles still 0.6% above the GEV),
p1 where contamination ~ 1e-4 (quantiles 0.00% above the GEV).
Quadrature: 192 levels (24 panels x 8 Gauss-Legendre nodes) on [0.95, 1).
